# Sudenaz-Do-an-dev-
Markdown nedir?
  Bir yazı yazma biçimidir,şeklidir diye düşünebiliriz. Normal bir metni veya yazıyı güzelleştirmek için klavyedeki semboller aracılığıyla șekil, kalın yada ince yazmaya yarıyor. Kelimenin sağına soluna işaretler koyularak yapılıyor.

README dosyası nedir ve ne işe yarar?
  README sayfanın en başında gördüğümüz "README.md" dosya adıdır. Sayfayı açan herkesin ilk gördüğü ad veya tanıtım gibi bişey. Projeye, dosyaya giren kişiye projenin ne olduğunu ve ne işe yaradığını açıklamaya yarar.

Proje versiyon/sürümleri nedir, nasıl belirlenir?
  Projeyi veya programı yaparken, geliştirirken yapılan güncellemeleri takip etmek, karışıklığı önlemek içindir. Belirlenmesi şu şekildedir sürümde bulunan üç ayrı kısımdan oluşur diyebiliriz bu üç kısımdan ilki Proje tamamen değiştirildiğinde, ortadaki yeni bir şey eklendiğinde, sondaki ise küçük hataları, sorunları düzeltmede artar. Bu şekilde belirlenir. :)
